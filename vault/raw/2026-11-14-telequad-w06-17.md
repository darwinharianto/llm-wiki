The following groups of GPRS subscriber information are defined: The following groups of non-GPRS subscriber information are defined: Overlapping data: Two different cases of overlapping within subscriber data are possible: This may be either: Unexpected data: Data which is received and cannot be further processed. Missing data: Data which is mandatory in a given context but is not received nor is valid data available locally. Optional data is data which is defined by the service description (see e.g. 3GPP TS 23.06x, 3GPP TS 23.08x and 3GPP TS 23.09x-series of technical specifications, 3GPP TS 23.015, 3GPP TS 23.271 and 3GPP TS 23.135) or by PLMN defined requirements but is not defined as mandatory data. Optional data: Data which is defined as subscriber data, but which is not required to form a self-consistent set of subscriber data; the context governs whether a specific parameter is optional. Mandatory data is defined by the service description (see e.g. 3GPP TS 23.06x, 3GPP TS 23.08x and 3GPP TS 23.09x-series of technical specifications, 3GPP TS 23.015, 3GPP TS 23.071 and 3GPP TS 23.135) and by PLMN defined requirements. The context governs whether a specific parameter is mandatory, e.g. the data set for a specific service may be optional, however if data for this service is present, then parameters within this data set may be mandatory. Mandatory data: Data required to form a self-consistent set of subscriber data. Shared GPRS subscriber data includes: Subscriber data only stored in the HLR is not part of shared subscriber data.
