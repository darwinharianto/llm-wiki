# Telecom Reference Sheet — 3GPP 45009-f00: Transmitter/Receiver Synchronisation

Ingested: 2026-11-14T05:19:54Z

3.2.1.3	Transmitter/Receiver Synchronisation The alternating transmission of the codec mode information requires synchronisation of transmitting and receiving ends, such that Codec Mode Indications and Codec Mode Commands/Requests are decoded in correct order.

This default phase of the Codec Mode Indication in downlink direction is called "odd", the alternative phase, one speech frame shifted, is called "even". The phase in uplink is always the same and is never changed.
