# Telecom Reference Sheet — 3GPP Spec 23108-g00 (03)

Ingested: 2026-11-14T05:19:51Z

7.1	General Clause 7 contains examples of how the network may group together the elementary procedures (i.e. the procedures defined in clauses 3 to 5) in order to provide normal service.

This is achieved by the network including in a L2 UA frame the same information field as that one received in the L2 SABM frame to which the UA frame responds. By comparing the two information fields the MS can verify whether it was the originator of the L2 establishment, because the service request contains the mobile identity.
