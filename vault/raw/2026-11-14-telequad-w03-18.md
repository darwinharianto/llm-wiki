# Conformance Testing (UE) — Specification Digest

Ingested: 2026-11-14T05:19:24Z

The role of STF 160 is to develop the reference TTCN code that enables the verification of the signalling protocol test cases. Supporting the 3GPP effort is a team of experts in Special Task Force 160 (STF 160), funded by 3GPP and volunteer companies. Spectacular progress has been made to make these Radio Frequency and Signalling Protocol conformance test cases available so soon after the LTE core specifications. 3GPP RAN5, the Working Group responsible for User Equipment (UE) testing, made significant progress during the recent Plenary meeting (#42), in Athens, with a set of LTE related test specifications being approved in Release 8 of the standard.
