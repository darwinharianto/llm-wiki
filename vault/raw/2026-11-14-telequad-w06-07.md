After the channel release is completed, the radio resources which were in use may be reallocated by the network. The data link layer is released explicitly as described in 3GPP TS 44.006. Once the transaction phase has been completed, the channel is released by the channel release procedure. 7.1.7	Channel release The channel mode modify procedure is initiated by the network sending a CHANNEL MODE MODIFY message and completed by the mobile station changing the mode of the TCH and sending back a CHANNEL MODE MODIFY ACKNOWLEDGE message. The channel mode modify procedure may be used when a traffic channel has been assigned e.g.: 7.1.6.1	Channel mode modify In this subclause, only the channel mode modify procedure is characterized. A variety of elementary procedures described in clauses 3 to 5 may be performed during the transaction phase. 7.1.6	Transaction phase Where ciphering is used, this procedure synchronizes the start of ciphering at the mobile station and in the network. Its purpose is to instruct the mobile station whether or not to use ciphering and which algorithm to use. Ciphering mode setting is initiated by the network. 7.1.5	Ciphering mode setting This may depend on the context. The network decides whether or not to use authentication. The authentication procedure also provides the mobile station with information from which a new ciphering key can be derived. It is initiated by the network. The purpose of authentication is to validate the identity provided by the mobile station . 7.1.4	Authentication By comparing the two information fields the MS can verify whether it was the originator of the L2 establishment, because the service request contains the mobile identity. This is achieved by the network including in a L2 UA frame the same information field as that one received in the L2 SABM frame to which the UA frame responds.
