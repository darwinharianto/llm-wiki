# Telecom Reference Sheet — 3GPP 21915-f00: Numerologies, waveform and frame structure

Ingested: 2026-11-14T05:19:49Z

5.5.4.1	Numerologies, waveform and frame structure Similar to LTE, OFDM with Cyclic Prefix (CP) is used as the downlink (DL) waveform for NR.

As shown in the figure for the 15 kHz case, each slot consists of 14 OFDM symbols (independently of the SCS) preceded by a cyclic prefix (CP). Note that, for the 60 kHz SCS, an extended CP is possible.
