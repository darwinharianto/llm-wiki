# 3GPP 45009-f00: Transmitter/Receiver Synchronisation (Protocol Summary #6)

Ingested: 2026-11-14T05:19:47Z

In case of reallocation failure and fall back to the channel before the reallocation attempt, the phase before the channel reallocation attempt shall be used again (except if a RATSCCH procedure is pending, see section 3.2.2.2 bullet 6). During a call, the phase of Codec Mode Indication may be changed in downlink by using a RATSCCH message. At call set-up, after a channel mode modify with consistent MultiRate configuration IE and after each reallocation of the circuit switched channel, the default phase (odd) shall be used in downlink direction. The phase in uplink is always the same and is never changed. This default phase of the Codec Mode Indication in downlink direction is called "odd", the alternative phase, one speech frame shifted, is called "even".
